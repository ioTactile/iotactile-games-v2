# App — IoTactile Games

Frontend Next.js de la plateforme **IoTactile Games**.

La documentation d’ensemble (stack, Docker, variables d’environnement, architecture) se trouve dans le [README racine](../README.md).

## Développement

```bash
# Depuis la racine : Postgres + Redis + API
pnpm docker:dev

# Dans ce dossier
pnpm install
pnpm dev
```

Scripts utiles : `pnpm lint`, `pnpm test`, `pnpm build`.
